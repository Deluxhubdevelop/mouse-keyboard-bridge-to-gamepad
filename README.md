# mouse-keyboard-bridge-to-gamepad
💸 Why is this free?
Because a controller emulator shouldn't require a key system, a link shortener, or a subscription.

The Linux kernel has had uinput built-in for over a decade. It's not a secret, and it's not "unbannable magic". It's just kernel-level input injection.

No injected code. No game file access. No memory reading. Just a virtual controller created with native system calls.

(This Working ONLY ON X11, I will be test on wayland distro).
